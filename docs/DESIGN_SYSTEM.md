# Design System

## Purpose

Maintain visual consistency across ReplyMate AI.

## Colour System

Choose a primary brand colour and supporting neutral colours during UI implementation.

All colours must support sufficient contrast in light and dark themes.

## Typography

Use a consistent type scale:
- Display
- Headline
- Title
- Body
- Label
- Caption

Support Bengali and Devanagari scripts with suitable font fallbacks.

## Spacing

Use a consistent spacing scale. Avoid arbitrary spacing values throughout the application.

## Components

Create reusable components for:
- Primary button
- Secondary button
- Text field
- Dropdown selector
- Permission status card
- Reply suggestion card
- Loading indicator
- Error message
- Confirmation dialog
- Empty state

## Interaction

- Provide visible pressed states.
- Disable actions while appropriate requests are running.
- Confirm destructive actions.
- Avoid unnecessary motion.

## Theming

Implement light and dark themes using centralized design tokens.
